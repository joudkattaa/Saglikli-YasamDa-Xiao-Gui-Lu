---
name: Denge profile age scope
description: User decision about which age data Denge may collect in account profiles.
---

For Denge, age is an optional number of years. Do not collect a full date of birth unless the user explicitly asks.

**Why:** The user chose the age-in-years option after considering full date of birth; this keeps collected profile data limited.

**How to apply:** Keep age optional, permit clearing it, and avoid adding birth-date fields to the profile without renewed direction.
